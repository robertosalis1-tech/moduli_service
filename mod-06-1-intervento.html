Il modulo non si è avviato

Il file è stato aperto in anteprima (allegato della Mail, app File, WhatsApp...): l'anteprima di iPhone mostra la pagina ma non esegue il modulo.

Come aprirlo su iPhone / iPad:

  1. Salvare il file in File (Condividi → Salva in File).
  2. Aprire Safari o Chrome e caricare il file da File (in Chrome: Condividi del file → Chrome; in alternativa usare l'app Documents di Readdle, tocca il file e si apre nel suo browser).
  3. Oppure aprire il file da un link web / cartella condivisa che si apre nel browser.

Su PC e Android basta aprirlo con Chrome, Edge o Safari.
